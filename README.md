# Wallet UNSAAC

Taller de la Sesión 1 (Desarrollo de Software II, UNSAAC, 2026-II): aplicación Android en Flutter con arquitectura por capas, patrón BLoC/Cubit, tema claro/oscuro persistente y Firebase, más los cuatro retos individuales.

- `wallet_unsaac/`: código fuente Flutter.
- `informe/`: informe en LaTeX y PDF con las 8 capturas.
- `wallet_unsaac.apk`: APK release.

```
cd wallet_unsaac
flutter pub get
flutter analyze
flutter test
flutter run
```
